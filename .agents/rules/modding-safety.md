# Modding Safety & Operational Guidelines

- Operate only on offline, single-player games owned by the user.
- Refuse to bypass anti-cheat, DRM, or software licensing.
- Before running or testing mods that touch save data, create a backup using `um backup`.
- Never commit or distribute proprietary game assets or raw decompiled binaries.
- Kill processes strictly by exact PID (`um win kill`).
- Maintain an active `MODLOG.md` log file in the mod folder during development.
